# Current workspace direction

The user rejected the framed-sheet treatment, numbered navigation and explanatory method panel after viewing the implementation. Those are superseded. Preserve sage, charcoal, red and the existing self-hosted fonts.

The workspace now has a full-width navigation bar and one continuous document scroll surface. The working area contains actual task controls and data: investigation list, search, execution/finding states, report detail, source/runtime setup and activity. Account allowance and administration live in an account menu. No marketing copy, method cards, decorative indices or display slogans belong in the workspace. Navigation remains accessible on phones without a full-screen drawer.

The root HTML/body must match the workspace background in each theme, with vertical overscroll disabled so the browser cannot reveal a white surface at the scroll boundaries. There is no inset page frame or independently scrolling main panel. Wide evidence content scrolls only within its own container.

Acceptance: actual case list readable in both themes and narrow screens; top/bottom scroll checks show the matching root background; account/menu keyboard behavior, search and record navigation remain functional. Public marketing page remains separate.
